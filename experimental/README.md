# Experimental Folder — Rules

This folder is a sandbox. Content here is draft, not canon.

## Rules

- Claude may write freely to this folder without explicit permission
- Nothing moves to canon without Drew's explicit sign-off
- Cards are created in batches of 9 (3 Red / 3 Blue / 3 Green)
- No new keywords introduced without discussion first
- The dev loop runs until red team is satisfied — cuts go to `rejected.md`
- Rejected cards are kept, not deleted — they may have future solutions

## Dev Loop

1. Read source material for the target creature or gap
2. Draft 9 cards using only existing keywords
3. Red team: balance, keyword compliance, creature fidelity, early-game fit, Oracle reward value
4. Cut failing cards → `rejected.md` with reason noted
5. Replace cuts with new cards, re-red-team
6. Repeat until all 9 pass
7. Present to Drew with summary of what was cut and why
