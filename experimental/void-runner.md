# Void Runner

*Tide Pulls Back arc. Dock encounter. Grunt threat.*

Smuggling crew. Use stolen resonant items as weapons. Some travel with Corrupted Bathers. Dangerous in numbers.

**Mind 2 / Body 3 / Soul 1 — HP 15**

**Passive — Stolen Item (1/combat):** Activate a stolen resonant item. DM chooses the effect: Stagger the target, Root the target, or gain Armour 1 until start of next turn.

**Passive — Crew Pressure:** While 3+ Void Runners are active in combat, all party members draw one fewer card at the start of each cycle.
