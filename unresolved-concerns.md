# Unresolved Concerns

A scannable index of everything currently open that will eventually need a decision or a fix — the things that otherwise sit buried in `memory.md`'s prose (Recently Shipped entries, Standing Reasoning, Pending Propagation) until someone rereads the whole file. **This is an index, not a third home**: each entry is a line or two plus a pointer to where the full trail lives. Add a line when a concern gets flagged; delete the line when it's resolved (`memory.md` keeps the history — this file only ever shows the present).

**What does NOT belong here**: deliberately open questions. This repo keeps quiet doubts and unresolved world-hooks on purpose (`CLAUDE.md`: "the open questions are on purpose") — who bears the Storm Seat, what the Ferryman reads, what's at the Coil's center. Those are design, not debt. This file is for actual debt: flagged issues, known imbalances, deferred decisions that shouldn't be forgotten.

Also not here: **Pending Propagation** (operational staleness — print sheets, sim sync) stays in `memory.md` where the Sync workflow already looks for it. Entries below may point there, but the ledger itself doesn't move.

## Mechanics & Balance

- **Even-matchup PvP mirrors are still more lethal than the 1-death-per-20-sessions target, though the mechanism fix already landed.** Targeting was reworked (random pick, pile on, drop on collapse) — death-occurred rate dropped from 45–62% to 41–48% in symmetric 3v3 mirrors, real progress, still nowhere near target. Drew's own caveat: mirrors between equal-ish parties were only ever testing the mechanism's direction, not validating the number. Now tested against a real 4-player Oracle-drafted party vs. the Patient Host — see below; the mirror-vs-real-encounter gap is closing, not the death-rate number itself. *Trail: memory.md, Standing Reasoning (the team-targeting rework entry) and the 2026-07-23 test-party entry.*
- **The Patient Host's kit-vs-stats question is answered; a scaled-party test still isn't possible.** REGISTERED reworked to actually express Mind 8 (exiles the most dangerous card it sees instead of just delaying it) rather than reading as a generic Scry-and-Ward card — win rate barely moved (78.0%→77.9%), confirming this was an identity fix, not a power one. What's still genuinely open: a scaled-party test (real gear/item progression vs. the Host) can't be run honestly without an item/gear progression system, which doesn't exist yet — parked by Drew ("let the host run his inn in peace. for now"). *Trail: memory.md, Pending Propagation (the parked entry) and the 2026-07-23 REGISTERED rework entry.*
- **Sim win-rate numbers involving any deck other than Frost/Steele carry a real, uncontrolled variable: deck-building skill.** Frost and Steele are the only precision-built decks in the whole roster — real players (Ollie, Kevin) building for their own real characters. Every other deck (mire/volk/sage/adept/warden/vanguard/tempo, garret/brasca/wyn/tallis, the Patient Host, every bestiary/NPC kit) is Claude-built, never given a deliberate optimization pass. Any win-rate test where NEITHER side is Frost/Steele (which includes tonight's party-vs-Patient-Host and Initiative-Shift-ablation numbers) is comparing two unknown-quality decks, not validating a balance question in isolation. Not urgent to fix — flagging so future test design accounts for it, e.g. by using Frost/Steele as one side when the goal is actually isolating an opponent's tuning. *Trail: memory.md, the 2026-07-23 6:36 AM entry.*
- **Three coreset cards grant Deadly to themselves, deferred to a future roll, with no way to use it sooner** — RETALIATE, OVERCOMMIT, SEED. Named directly by Drew as worth fixing once the keyword-lab timing finding (self-granted Deadly pays off a full lap later than a foe-targeted debuff or an ally-granted one) made the cost visible. Not redesigned yet — which fix fits each (same-attack immediate, retarget to an ally, accept the cost and reprice) is a real per-card call. *Trail: memory.md, the 2026-07-23 11:15 PM entry.*
