# Archetypes

Card lists, one file per archetype. **No card text lives here** — `cards/` holds every full card.

Archetypes are an **index, not a filing system.** A card has exactly one home bucket (`cards/buckets/`) because it can only live in one file; it can carry any number of archetypes, and an archetype routinely spans several buckets. The Gambler is the clearest case: TABLE STAKES homes under self-inflicted cost while GAMBLER'S RUIN homes under damage amp.

This layer exists because the cards that resist mechanical sorting are precisely the ones with archetype identities — SEED (Cultivator), GAMBLER'S RUIN (Gambler), WAITING GAME (Mirror) all had to be hand-assigned during bucketing, because their identity is a strategy rather than a mechanic.

**Never surfaced to players.** Drew: *"at the table archetypes aren't revealed, they are naturally discovered."*

Meaning, status, and design reasoning for every archetype: `agent-tools/archetypes.md`.
