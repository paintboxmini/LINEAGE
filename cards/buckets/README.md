# Buckets

Card lists, one file per bucket. **No card text lives here** — `cards/` holds every full card, and these files only record which cards belong where.

Each card has one **home** (the bucket it moves to when the Oracle pool is slimmed — a card can live in only one file) and may be **also indexed** in any number of others, because Effect, Defensive Bonus and Special Rule frequently do different jobs. Fifty of the 143 core cards carry a secondary. Filing by home alone would hide real coverage: *defense* homes 16 cards and indexes 30.

A bucket names **what a card is for**, never the keyword it happens to use.

Assignment, reasoning, and the hand-corrected entries: `agent-tools/core-bucket-assignment.md`.
Multi-label *function* analysis is a different vocabulary and lives in `agent-tools/card-corpus-analysis.md`.

**Currently core-set cards only.** Signature sets, location pools, and `cards/stat-adjusters.md` are not yet bucketed.
