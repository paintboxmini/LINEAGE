# Buckets

Card lists, one file per bucket. **No card text lives here** — `cards/` holds every full card, and these files only record which cards belong where.

Each card has one **home** (the bucket it moves to when the Oracle pool is slimmed — a card can live in only one file) and may be **also indexed** in any number of others, because Effect, Defensive Bonus and Special Rule frequently do different jobs. 143 of the 341 cards carry a secondary. Filing by home alone would hide real coverage: *defense* homes 16 cards and indexes 30.

A bucket names **what a card is for**, never the keyword it happens to use.

Assignment, reasoning, and the hand-corrected entries: `agent-tools/core-bucket-assignment.md`.
Multi-label *function* analysis is a different vocabulary and lives in `agent-tools/card-corpus-analysis.md`.

**All 341 cards are bucketed** — core sets, signature sets, location pools and stat adjusters. Colour-set membership (`red`, `blue`, `green`, `colorless`) lives here too, since `cards/` is one file per card and no longer groups by set.
