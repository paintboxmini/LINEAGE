# Wall-Reader — Signature Cards

**NEVER LIFTED**
RED — BODY — COIL
Attack: Body + d6
Effect: This attack cannot be Evaded.
Defensive Bonus: Gain Resist.
Range: Melee
*"One hand has been on this wall longer than you've been alive."*

**YOU CHANGED WALLS**
RED — BODY — COIL
Attack: Body + d6
Effect: If the defender changed position since their last turn, this attack gains Deadly.
Defensive Bonus: Gain Resist 2.
Range: Melee
*"It only ever needed you to move."*

**STILL COUNTING**
GREEN — SOUL — COIL
Attack: Soul + d4
Effect: If you have not changed position this combat, this attack gains Deadly.
Defensive Bonus: Gain Resist.
Range: Both
*"Nobody's counted the laps. It has."*
