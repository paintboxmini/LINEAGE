# Briarwatch Jackalope — Mechanics

**Cards:** `cards/bolt.md`, `cards/freeze.md`, `cards/nip.md`, `cards/quickstep.md`
**Mind 1 / Body 1 / Soul 3 — HP 7**
**Creature Threat Rating:** 5
**Deck (5 — 1 Blue / 1 Red / 3 Green):** FREEZE *(blue)* · NIP *(red)* · BOLT, QUICKSTEP, MOCKERY *(green)*

## Encounter Setup

Start with 3 Jackalopes: 1 Frontline, 2 Backline. They rotate constantly using Bolt. Works anywhere with room to circle — a ruined courtyard, an open hedgerow, a fence line between fields.

*Teaching moment: Rushdown becomes the obvious tool. The system teaches positioning naturally.*

---

## What Players Learn

| Mechanic | How they learn |
|----------|----------------|
| Positioning | Jackalopes constantly change positions |
| Rushdown | Best tool against constant repositioning |
| Initiative | Jackalopes move early (Soul 3) |
| Low HP enemies | Fights resolve quickly |
| Enemy intent | Survival, not slaughter |
