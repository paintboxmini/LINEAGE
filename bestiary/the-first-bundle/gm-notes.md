# The First Bundle — GM Notes

Run it as scenery for as long as the table lets you. It is in the establishing description of the field. It is in the description again on the second visit. Nobody rolls anything.

The Folded stage is a real window and should be played honestly — if a player says they attack the heap, that attack lands for double, and the fight is genuinely shorter. Do not soften this. The encounter's whole argument is that the moment to act was earlier than anyone felt sure about, and it only means something if acting early actually works.

Armour 2 does not arrive until the third stage on purpose. Early damage matters more than late damage against this thing, which inverts the usual shape of a boss fight and rewards the party that committed.
