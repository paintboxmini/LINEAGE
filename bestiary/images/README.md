# Images

Creature art, one file per piece, named for the creature it shows. Each one is referenced from that creature's file.

*GM side, like the rest of `bestiary/` — art that goes to players goes out printed, on a binder page or a card (`binder/README.md`).*

**At the table they are position markers** *(Drew, 2026-10-16)*: a creature's art is printed at card size, sleeved, and set down at Frontline or Backline for each creature in the fight. **The recipe:** nine copies to a letter page at the card sheet's geometry — 60 × 84 mm, 3 × 3, 10 mm page margin (`printing/generate-cards.py`) — with the image cropped to fill the card. Built in chat like every other printed artifact (`printing/README.md`).
