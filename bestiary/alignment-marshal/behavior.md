# Alignment Marshal — Behavior

It is not a guardian. It is not a villain. It is a correction mechanism.

**Its purpose:** Return system to operational alignment. Foreign bodies detected. Calibration compromised.

It doesn't target intelligently. It corrects interference. When a player pulls a lever, disables a vent, or adjusts a rail, the Marshal shifts focus toward them.

It moves through maintenance shafts. Climbs internal scaffolding. Emerges where it shouldn't. It uses vertical movement. It collapses bridges behind them. It shoves players toward unstable platforms.

Not a damage sponge. A positioning predator.
