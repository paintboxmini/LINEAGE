# Fermata

*Solitary boss encounter. `places/the-silent-choir.md` — guardian of the Silent Choir, keeper of what the Silent Blade was cut from.*

**Bespoke — deck size does not equal total stats.** The formula baseline for Mind 10/Body 12/Soul 20 would be a 42-card deck; this one is fixed at 12, the same exception `bestiary/hullback/README.md` set the precedent for. Big numbers, small toolkit — Fermata has held the same handful of moves for longer than it has a name for how long that's been.
