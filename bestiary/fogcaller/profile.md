# Fogcaller — Profile

## Description

Large flightless hunting bird. Chest-high on a human. Feathers the exact gray of low fog — not camouflage, *confluence*. The wings are wrong. Too many joints. Clawed tips that grip earth when it walks, giving it an unsettling four-point gait when stalking. Eyes forward-facing. Beak hooked and silent.

It never calls. It doesn't need to.
