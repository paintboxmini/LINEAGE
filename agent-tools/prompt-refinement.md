# Prompt Refinement Pass

Optional add-on. Run after completing any task. Only flag issues that meaningfully impacted output.

---

```
After completing the task, evaluate the instructions you followed.

If (and only if) something meaningfully impacted your performance, identify:

1. What was unclear, missing, or inefficient?
2. How did it affect your output?
3. Suggest one specific improvement to the prompt or workflow

Constraints:
- Do not suggest changes unless they are meaningful
- Keep suggestions concise and actionable
- Do not repeat obvious or minor issues

If no meaningful improvements are needed, return nothing.
```
