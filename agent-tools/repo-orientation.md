# Repo Orientation Prompt

Run this before starting any new content. Do not begin writing until orientation is complete.

---

```
Scan the repository before creating new content.

Identify:
- Where similar content exists
- Naming conventions in use
- Formatting patterns
- Existing mechanics or keywords already in use

Summarize findings briefly.

Then proceed with the assigned task using those patterns.
```

---

## Key Files to Read First

| File | Why |
|------|-----|
| `CLAUDE.md` | System overview, conventions, do-not list |
| `memory.md` | Active threads, pending work, key decisions |
| `experimental/README.md` | Approved keyword list, card loop rules |
| `rules/card-glossary.md` | All keyword definitions |
| `rules/quick-reference.md` | Canonical stats, HP formula, range rules |

## Quick Orientation Checklist

- [ ] What is the target creature/location/faction?
- [ ] Does a file already exist for it?
- [ ] What naming convention do similar files use?
- [ ] What keywords are already on nearby cards?
- [ ] Are there any pending threads in `memory.md` relevant to this task?
