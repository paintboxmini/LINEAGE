# Eclipseria — Reference Map

`eclipseria-reference-map.png` — an AI-generated prototype, built as a style and shape reference for Drew's own hand-drawn physical map (2026-08-16). Not a finished asset, not player-facing.

**A living note — keep this current as place content changes,** not just a one-time caveat list. If a place file's geography changes in a way that makes the image more (or less) wrong, update the relevant section below rather than leaving it to drift. The prompt that generates this image is tracked the same way, in `eclipseria-map-prompt.md` — update both together.

---

## Wrong on the image

- **The road network.** Denser than what actually exists. The real network is six segments, no more: the three edges of the Glasslight Reach / Turnroot Weald / Vulture's Nest triangle, plus one spoke from each of those three corners in to Eclipseria at the center. See `world/geography-overview.md`, The Kings Road.
- **The throne icon marking the capital.** A generic cartography symbol for "seat of political power," not a claim that Eclipseria is a **Seat** in the cosmological sense (`world/seats.md`). The two senses of "seat" colliding here is coincidental, not intentional overlap — flagging it so it doesn't read as one later.
- **Turnroot Weald's relationship to Ashfall Wastes.** Canon has Turnroot specifically wrapping Ashfall's *eastern* edge (`world/geography-overview.md`; `factions/the-masons.md`, Known Works — the watchtower line). The image just shows the two as adjacent, overlapping blots — the wrap isn't legible as its own shape.

## Missing from the image

- **Briarwatch.** Missing from the current PNG. Added to `eclipseria-map-prompt.md` already — this stays listed here until the image is actually regenerated. Sits a day's travel west of Vulture's Nest, cut into Turnroot Weald's own edge (`places/briarwatch.md`).
- **Havenrise, Roaat, Canille, Pneum, Apnea.** All five have stated positions in `world/geography-overview.md`'s coordinate table and arguably belong on a "known lands" map the same way Briarwatch does. Left off here, not confirmed as intentional.

**Correctly absent — do not add these:**
- **The Coil.** Its own lore states it doesn't appear on charts (`world/geography-overview.md`; `places/the-coil.md`). Leaving it off this image is accurate, not a gap.
- **Clayhollow, Veldmire, Weatherheart Vale.** No stated position anywhere in canon. `world/geography-overview.md` itself declines to place them on the coordinate table for the same reason — inventing a spot for them here would be inventing geography, not reference art.

## Accepted deviations

- **Abyssal Ruins sitting offshore, apart from the mainland.** Drew's call (2026-08-16) — safe to leave as-is. Still worth remembering that canon has no stated way to actually reach it out there, since nothing sails the Unheld (`world/geography-overview.md`: "Nothing sails it. Nothing fishes it."). Not treated as an error; just an open thread if it ever needs reconciling.
